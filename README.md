# EasyTranslate - AI 驱动的双语阅读

一个类似沉浸式翻译的浏览器扩展，支持划词翻译和双语对照阅读。

## 功能特性

- 🎯 **划词翻译**：选中文本后点击浮动按钮，即时翻译
- 📖 **双语对照**：整页翻译，原文与译文段落对照显示
- 🤖 **AI 驱动**：支持 OpenAI 兼容 API（Groq、OpenRouter、Ollama 等）
- ⚡ **快速响应**：流式翻译显示，缓存已翻译内容
- 📚 **生词本**：一键把译后的单词/短语加入生词本，支持搜索、导出 JSON/CSV
- 🔊 **音标读音**：保存单词后自动补全音标 + 读音，复习时原文旁一键播放 / 自动播放
- 🎴 **每日复习**：生词本里的「今日新词」一键进入闪卡复习模式，自评「不认识 / 模糊 / 认识」后自动记录
- 🔒 **隐私安全**：API Key 本地存储，支持 HTTPS

## 技术栈

- Manifest V3
- TypeScript
- Shadow DOM + Web Components
- Vite 构建工具

## 安装使用

### 环境要求

- Node.js 18+
- Chromium 内核浏览器（Chrome、Edge、Arc 等）

### 1. 下载源码

```bash
git clone https://github.com/huangxinghui/easy-translate.git
cd easy-translate
```

### 2. 安装依赖

```bash
npm install
```

### 3. 构建插件

```bash
# 生产构建
npm run build

# 或开发模式（带热更新）
npm run dev
```

构建完成后，会在项目根目录生成 `dist/` 文件夹。

### 4. 加载到浏览器

#### Chrome / Edge

1. 打开浏览器，地址栏输入 `chrome://extensions/`（Edge 为 `edge://extensions/`）
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择项目中的 `dist` 目录

![加载扩展示意图](docs/install-step.png)

#### 加载成功标志

- 浏览器工具栏出现扩展图标（🌐）
- 点击图标弹出设置面板，说明加载成功

### 5. 配置 API Key（首次使用必须）

1. 点击浏览器工具栏上的扩展图标 → 选择「打开设置」
2. 选择翻译服务提供商：
   - **Groq**（推荐，速度快，有免费额度）
   - **OpenRouter**（模型选择多）
   - **自定义**（Ollama 本地部署或其他 OpenAI 兼容服务）
3. 填入对应的 API Key
4. 选择目标语言（默认：中文简体）
5. 点击「保存设置」

#### 推荐免费 API 服务

| 服务           | 网址                     | 特点                   |
| -------------- | ------------------------ | ---------------------- |
| **Groq**       | https://console.groq.com | 速度极快，免费额度充足 |
| **OpenRouter** | https://openrouter.ai    | 支持模型多，按需付费   |
| **Ollama**     | http://localhost:11434   | 本地运行，完全免费     |

### 6. 开始使用

#### 划词翻译

1. 在任意网页上选中一段文本（≥1 个字符）
2. 选区附近会出现一个粉色浮动按钮（🌐）
3. 点击按钮，弹出翻译结果弹窗
4. 弹窗中可「复制译文」「交换」原文/译文，或「⭐ 加入生词本」保存词条

> 💡 点击页面空白处或按 `Esc` 可关闭弹窗

#### 生词本

划词弹窗里的「加入生词本」按钮会把原文、译文、音标、来源 URL 一并保存到本地。再次选中同一文本时按钮会显示「✓ 已加入」，再次点击可移除。

打开扩展「设置」页面，最下方有**生词本**卡片：

- 顶部显示词条总数，支持关键词搜索（匹配原文、译文、笔记）
- 每条记录可单独删除，附带的音标按钮可以一键播放发音
- 一键导出为 **JSON** 或 **CSV**（可作为 Anki / 自定义生词本的导入源）
- 「清空生词本」按钮配合确认提示使用，避免误删

> 💡 词条 ID 根据「原文 + 目标语言」生成，重新翻译同一词条会更新译文，保留首次保存时间。

#### 音标与读音

划词弹窗选中英文单词时，会请求 [dictionaryapi.dev](https://dictionaryapi.dev) 拿到音标 + 音频 URL，连同译文一起写入词条。如果保存时没拿到（中文/短语/网络抽风），后台会异步重试一次给词条补上读音，下次查看就能看到。

- **生词本列表**：每条记录的音标行右侧有一个醒目的播放按钮，点击听发音（按钮会在播放时高亮）
- **复习模式**：原文旁边独立加了一个圆形播放按钮，不需要先点「显示答案」就能听；加载新题时还会自动播一次，帮助你先听音回忆

> 💡 只对纯英文单词（支持连字符 / 撇号如 `self-esteem`、`don't`）会自动补全，其他词条会跳过这步以免产生噪音请求。

生词本卡片顶部会出现“今日新词 N 个 [开始复习]”的金色横幅（只包含本地日期下创建的词条）。点击按钮进入闪卡模式：

1. 先看到词条的**原文**（大字体居中），「显示答案」按钮可以揭晓译文 + 音标 + 来源
2. 点下方三档自评中的一个进入下一题：
   - **不认识**（红）：今天第一次接触，需多加复习
   - **模糊**（黄）：有印象但不熟，下次再来看
   - **认识**（绿）：完全掌握
3. 答完本轮后显示「本轮总数 / 认识 / 模糊 / 不认识」总结，可以「再来一轮」反复刷，或「返回生词本」

每次自评会在词条上记录 `lastReviewedAt` 和 `reviewCount`，不引入复杂的间隔重复算法。

> 💡 词条即使复习多轮也不会从“今日”队列里移除——欢迎反复刷加深记忆。

#### 整页双语翻译

1. 打开任意有可读内容的网页
2. 按快捷键 `Alt + T`，或点击扩展图标选择「翻译页面」
3. 页面每段原文下方会插入对应的译文段落
4. 再次按 `Alt + T` 可恢复原始页面

> 💡 翻译过程中按 `Esc` 可取消

## 快捷键

| 快捷键    | 功能                        |
| --------- | --------------------------- |
| `Alt + T` | 翻译/恢复当前页面           |
| `Esc`     | 关闭翻译弹窗 / 取消整页翻译 |

## 常见问题

**Q：为什么翻译 Twitter/X 页面提示「页面没有可翻译的内容」？**

A：Twitter/X 的推文文本使用 `div` 标签包裹，旧版提取器将其视为容器而跳过。已在 [d026cad](https://github.com/huangxinghui/easy-translate/commit/d026cad) 修复，支持通过 `data-testid="tweetText"` 等平台标记识别 div 文本容器。

**Q：插件在某些页面报错 "The provided markup is invalid XML"？**

A：XHTML 文档要求 `innerHTML` 传入良构 XML。已在 [d026cad](https://github.com/huangxinghui/easy-translate/commit/d026cad) 修复，将所有 `<img>`、`<br>` 等空元素改为自闭合形式。

**Q：支持 Firefox / Safari 吗？**

A：当前仅支持 Chromium 内核浏览器（Chrome、Edge、Brave、Arc 等）。Firefox 需要额外适配 Manifest V2/V3 差异，计划后续支持。
